# Conditional Astra guidance

Load this reference only when the project configuration identifies GPT-6 Astra
as the lead. It is a review checklist based on model guidance, not evidence of
local performance gains and not permission to change the configured model or
effort.

For an observed failure, ask whether ambiguous stop or approval wording blocked
already-authorized work; delegation was useful and explicitly scoped rather
than duplicated; verification expanded beyond the requirement without evidence;
verbosity or repeated history crowded out decisive facts; or a new instruction
conflicts with a user request or sibling skill. Turn at most one evidenced issue
into the normal falsifiable improvement proposal.

Use the project-selected roles: the configured lead handles difficult diagnosis
and synthesis, economical configured workers gather bounded evidence, and an
independent configured model or human judges the change. Inspect the actual
host's supported controls before changing settings. Product guidance and API
examples do not authorize configuration changes or prove a measured gain.

Source: [OpenAI Astra guidance](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-6-astra),
inspected 2026-09-13. Recheck this dated guidance before relying on it after a
model or harness change.
